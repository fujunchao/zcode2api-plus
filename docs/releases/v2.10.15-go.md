# v2.10.15-go

## 代理软失败隔离：能连但跑不动的线路不再被使用

线上复盘（2026-10-17 网关日志，16.2 小时）显示，健康巡检只认「彻底连不上」：
探针对目标站点根路径发一次 6 秒 GET，能连但大包传不动的线路每次判健康。408/524 又是代理返回的
真实 HTTP 响应，`IsEndpointUnreachable` 只认传输层错误，因此这类失败既不触发复核、也不产生删除证据。
实测一条线路在 3 小时 32 分里反复超时，账号一直被绑在上面。

本版新增**软失败统计**：完整成功计入分母，传输层超时/连接重置、HTTP 408/504/524 计入分子。
窗口（默认 30 分钟）内尝试数 ≥3、软失败 ≥3、失败率 ≥50% 时，把该线路移出自动选线 30 分钟，
并把绑定在它上面的账号改派到其它线路。

- **只隔离，不删除**：不改 `Enabled`、不改代次、不删配置，到期自动回池；删除仍只由既有
  「两次新鲜网络复核 + 独立对照」决定。隔离状态持久化在内部 meta，重启保留。
- **续期有节流**：隔离期内再命中按 30/60/120/240 分钟逐级延长，每 5 分钟最多升一档。
- **保护名单照旧**：默认出口、托管默认出口与「禁止自动删除」的节点只记录不隔离。
- **永不掉直连**：没有可用替代时保持原绑定，宁可继续用一条慢线路也不落到直连。
- 失败率只统计「成功 + 软失败」，405/402/429 等业务语义不参与，避免稀释。

## 新导入线路先体检再上岗

订阅新增的线路此前没有任何巡检入队动作：落库即 `Enabled=true`，下一次风控换线就可能抽中它，
而全量巡检要等 30 分钟。现在导入后 15 秒内入队一次网络检查，**结果落库前不参与自动选线**。

- 门禁覆盖「未取走」与「已取走但结果未落库」两个阶段，不留空窗。
- 门禁最长 120 秒（`ZCODE_PROXY_FRESH_GATE_SECONDS`），超时放行；全池被挡住时按既有放宽逻辑兜底。
- 首检失败只隔离、不删除：刚出炉的一次探测不足以删除一条线路。

## 全量巡检不再被单点复检顺延

`netNext` 此前在每一轮开头都被重置为「当前 + 间隔」，包括只查一条线路的故障复检。
活跃期复检中位间隔数十秒，30 分钟的全量轮实际永远等不到——空闲线路上的坏点从未被扫到
（16.2 小时日志里 230 轮 `checked` 最大只有 7，全量轮从未命中故障）。

现在只有全量轮推进定时器；日志同时增加 `whole=0/1`，并在全量轮开始时打一行
`stage=probe whole=1 checked=N`，便于确认它真的在跑。

## 后台

`/api/health/summary` 增加 `soft` 字段，返回每条线路的尝试数、失败数、最近信号、隔离到期时间与连续次数。
本版未改前端界面，柜面展示沿用既有巡检页。

## 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `ZCODE_PROXY_SOFT_QUARANTINE` | `true` | 总开关；关闭后仍记账但不隔离 |
| `ZCODE_PROXY_SOFT_WINDOW_SECONDS` | `1800` | 统计窗口 |
| `ZCODE_PROXY_SOFT_MIN_ATTEMPTS` | `3` | 窗口内最少尝试数 |
| `ZCODE_PROXY_SOFT_MIN_FAILURES` | `3` | 窗口内最少软失败数 |
| `ZCODE_PROXY_SOFT_MIN_RATE_PERCENT` | `50` | 失败率下限 |
| `ZCODE_PROXY_SOFT_QUARANTINE_MINUTES` | `30` | 首档隔离时长 |
| `ZCODE_PROXY_FRESH_GATE_SECONDS` | `120` | 新线路冷启动门禁有效期 |

## 升级与验证

无需迁移：软失败状态存于内部 meta 键 `proxy_soft_failure_state`，不进设置快照、不暴露给
`/api/settings`；首次启动自动初始化。关闭开关即回到旧行为，已产生的隔离状态不再延长，
到期后自动回池。

回归覆盖：窗口阈值与低失败率、续期阶梯与封顶、静默归零、直连与非代理出口不计数、
重启保留、总开关只记账不隔离、隔离后改派、全池隔离时放宽、新导入线路的入队/取走/落库门禁/
超时放行、408/504/524 与取消/断流/风控的分类，以及全量轮不被单点复检顺延。
所有自动化验证由 GitHub Actions 执行，分支 CI 与发布工作流复用的完整 CI 均为门禁。

后续阶段（吞吐探针、长隔离自动停用）见[实施计划](../plan-proxy-soft-quarantine-20261017.md)。
