# v2.10.11-go

## 健康巡检面板改版：摘要行 + 抽屉

巡检的判定逻辑与配置项完全不变，本次只改**呈现方式**。

- **摘要行常驻**，只回答「现在有没有问题」：按优先级取第一条结论——结果保存失败 →
  对照暂停 → 严格删除暂停 → 未启用 → 正在检查 → 有待核查线路 → 正常。正常时只有一行，
  不再需要绕过配置区才能看到状态。
- **详情与配置各自走抽屉**。详情内分「网络可用性／模型可用性／诊断记录」三个标签，
  待核查条数直接标在标签上，不用切换就能看出哪一层有问题。诊断记录默认每次只占一行，
  点击才展开样本链（此前固定渲染最多 8 个徽章 × 20 次，长到无法扫读）。
- **配置表单分基础与高级**，高级默认折叠。自动覆盖＋自动择优（v2.10.10 起的默认值）下
  不再渲染线路与账号列表，**表单长度不再随线路数量增长**。
- **出口组声明移出巡检表单**，改为按线路独立声明。它是拓扑声明而非服务器探测到的出口 IP，
  文案保留该限定；自动退役仍要求目标与参考属不同出口组。
- **提示按严重性分三级**：存储失败为错误、对照暂停与证据不完整为警告、一次性迁移提示为
  可关闭的信息条，取代此前四条同等视觉权重的平铺。

## 升级与兼容

- 判定机制、配置项语义、API 契约与数据库结构**均未改动**：成对轮次证据、十分钟窗口、
  两轮对照、严格退役事务、预算与免测规则一律沿用。
- 摘要行的结论只由现有 `ModelProbeSummary` 字段推导，不新增后端字段，**无需迁移**。
- 出口组仍保存在同一配置键中；已有声明在改版后原样保留，只换了编辑入口。
- 一次性迁移提示可关闭，按配置 revision 记录，配置再次变化后会重新提示。
