# v2.13.5-go

修复 C1 断流闸门与 C2 重试选线的时间边界，并保存尚未触发隔离的首次断流。

- **C1 改为滚动窗口**：保存每次断流时间，只淘汰真正超过窗口的样本。隔离恢复后再次失败，不再因为最早一次断流过期而丢掉仍有效的后续样本；默认仍是最近 60 分钟累计 2 次。
- **C1 首次样本立即落盘**：不再等到触发隔离才保存；成功清除连续失败或观察期状态时同步保存，防止重启恢复旧失败。写入失败保留内存记录，下次记录或正常关闭时重试。
- **C2 各线路独立计时**：有效期从该线路最近一次断流起算。同内容先在 A 线失败，119 秒后在 B 线失败，第 121 秒重试仍会避让 B，已经过期的 A 不被额外续期。并发收尾的旧时间不会覆盖新时间。
- 补充滚动窗口、非默认阈值、重启、旧版状态兼容、保存失败重试及逐线路过期回归，并纳入远端 10 次重复验证。

现有开关和默认值保持不变。C2 仍采用内容指纹识别；无可用替代线路时沿用现有选号回退策略。

无需手工数据库迁移。旧版只记录计数和窗口起点，无法恢复每次断流的精确时间；升级时按原起点保守迁移，之后的新样本逐次记录。旧版尚未落盘的首次样本无法追溯恢复。

二进制：Linux amd64/arm64、macOS amd64/arm64、Windows amd64。
镜像：`ghcr.io/fujunchao/zcode2api-plus:2.13.5-go` 与 `latest`。
