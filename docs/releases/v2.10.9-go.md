# v2.10.9-go

## 统一代理健康巡检

- 原网络自动巡检与账号模型巡检合并到一个管理器、一个代理页面板；旧设置入口保留兼容别名，不再启动独立清理循环。
- 网络层无需账号，动态覆盖全部启用代理及后续新增线路，保留多入口可达性、防护拦截、逐入口状态和耗时；网络通过后，模型层才按账号资格与独立预算检查 5.3f。
- **网络首次异常不删除**：默认等待 10 秒独立复核，再检查健康参考线路或无凭据直连。复核恢复则保留，参考也异常则不删除；观察模式同时约束两层。
- 网络周期、模型周期及网络复核等待均可配置。大池分批推进，网络探测不扣模型请求预算；网络复核不会自动重放连接失败的模型请求。
- 普通自动账号继续使用原子改派，固定业务节点的托管账号仍等待，不擅自回到取额池或直连。正常在途业务流不被重新发送。

## 升级与兼容

- 仅使用旧网络巡检的部署保留其启用、周期及自动处理模式，新增二次复核；不会因此自动打开模型请求。
- 原“模型仅观察、网络自动清理”的混合配置保守合并为仅观察，并在界面提示重新确认，避免扩大自动删除权限。
- 设置及代理代次在真实出站和删除时复核；旧配置、取消或重启的半轮证据不能操作新状态。
- 原单条／全部连通性测试仍只读；新增“立即健康检查”执行当前统一策略。网络记录保留首轮、复核和参考结果，模型 405 严格规则继续独立。

## 验证

回归覆盖首轮误删、复核恢复、持续故障与健康参考、全局故障、无账号检查、动态新增、分批覆盖、仅观察、设置兼容、配置／线路变更、重启、模型连接失败不重放及独立预算。完整 CI 与发布验证均由 GitHub Actions 执行，新增十次统一巡检合同重复验证；未在开发机运行自动化测试或操作生产账号。
