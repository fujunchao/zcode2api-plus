# v2.1.4-go

代理自动巡检接入后台设置页：开关与巡检间隔可直接在 UI 上修改，即改即生效，无需重启、无需改环境变量。

## 新功能

### 设置页新增「線路自動巡檢」卡片

v2.1.3-go 引入的代理自动巡检此前只能通过环境变量配置，本版本起纳入「系統設定」页统一管理（与「每日定時領取」同一套模式）：

- **开关**：勾选即开启自动巡检，取消勾选后线路只由人工管理（不再自动检测、自动移除）。
- **巡检间隔（分钟）**：最小 1 分钟，从下一轮起按新值执行。
- **生效方式**：两个环境变量（`ZCODE_PROXY_HEALTH_ENABLED` / `ZCODE_PROXY_HEALTH_INTERVAL`）降级为**默认值**——在设置页保存过一次后，以设置页的值为准；改动即时生效，无需重启容器。
- 卡片内已明示巡检的处置逻辑：检测不通过的线路会被**自动移除**，绑定账号按「空閒线路优先 → 绑定数最少 → 直连兜底」自动改派；全部失败且直连也不可达时判定为本机网络故障，跳过移除。

## 文档修正

- v2.1.3-go 发版说明中巡检间隔的环境变量名误写为 `ZCODE_PROXY_HEALTH_INTERVAL_MINUTES`，正确名称是 **`ZCODE_PROXY_HEALTH_INTERVAL`**（无后缀），已更正。

## 升级

```bash
docker compose pull && docker compose up -d
```

升级后进入「系統設定」页即可看到「線路自動巡檢」卡片；未在 UI 上保存过的情况下，行为仍由环境变量（或默认值：开、30 分钟）决定，与 v2.1.3-go 完全一致。
