# v2.9.4-go

补齐账号池的按模型额度汇总，使其与仪表板一致。

- 账号池移除混合模型的“总额度（剩余）”，改为 GLM-5.3、GLM-5.3-Flash 两张独立额度卡。
- 分别显示总额、已用、剩余及账号/额度项目数量，支持未知、零额度和部分数据提示。
- 复用后端汇总逻辑及前端卡片，随账号列表的 5 秒轮询及刷新操作一起更新，无额外状态接口请求。
- 顶部为非归档账号全池快照，不随明细筛选或分页变化；保留每个账号的模型、套餐明细及到期信息。
- 不改变数据库结构、上游额度和调度规则；替换程序或镜像并重启，刷新后台页面即可。

二进制：Linux amd64/arm64、macOS amd64/arm64、Windows amd64。
镜像：`ghcr.io/fujunchao/zcode2api-plus:2.9.4-go` 与 `latest`。
