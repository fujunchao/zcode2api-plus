# v2.11.7-go

## 3.17.1 身份段按真实抓包逐字节修正

v2.11.6-go 把身份段换成 `dBa` 变体后仍是 405/3012。用官方 3.17.1 客户端
（新账号，可正常对话）的 `model-io` 抓包比对，定位到最后一处字节差异：

| 项 | 真实 3.17.1 | v2.11.6-go | 差异 |
|---|---|---|---|
| block 0 | `You are ZCode, an interactive agent`（35 字符） | 相同 | 无 |
| 身份段（第 0 字节→身份段末尾） | 1231 字符，sha16 `4058874023c7541f` | 1317 字符 | 多 88 字符 |
| system 块数 | 3（35 / 3119 / 3794） | 2 | 少动态块（含用户私有路径，不可逐字节校验） |

**根因**：身份段 Harness 的第 9 条项目符号在 3.17.1 里是模板字面量

```js
${e ? "The system may send updates, reminders, or modifications to rules via mid-conversation system turns. These are system-controlled, unlike function results." : "..."}
```

我们的静态提取没有展开它，把 `${…}` 原样写进了档案（多 88 字符）。
真实桌面会话 `e=true`，只发前半句：

> ` - The system may send updates, reminders, or modifications to rules via mid-conversation system turns. These are system-controlled, unlike function results. Hooks may intercept tool calls; treat hook output as user feedback.`

### 本版改动

1. `internal/upstream/zcode_system_3171.json` 的身份段改为**抓包原文**（1229 字符正文，
   连分隔换行共 1231）；block 0 与抓包一致。
2. 桌面上下文段沿用既有静态文本：抓包显示该段含 `C:\Users\<用户>\…\genUiOutputDirectory`
   等**用户私有路径**，上游不可能逐字节校验它。
3. 回归测试新增 `identity_chars` / `identity_sha16` 双重锁定（3.16.x：1213 /
   `fb4777a371fac341`；3.17.1：1231 / `4058874023c7541f`），差一个字节即失败。
