# v2.10.13-go

## 账号池异常分组

- 账号池顶部新增「异常」分组及数量，位于「用完」与「停用」之间。一键查看风控失效、凭据异常等当前失效账号，无需手动归类。
- 可继续叠加「风控拦截」错误类型筛选，只看风控失效账号，再使用既有批量恢复、停用和删除操作。切换筛选清空勾选，批量操作只针对当前可见的选中账号，删除保留确认。
- 临时冷却、本地隔离及正常账号的历史错误不计入异常分组；归档账号保持独立，初始化阻塞仍优先归入初始化。已停用但状态仍为失效的账号继续保留在异常组。
- 分组数量随账号查询刷新，恢复正常或转入冷却的账号自动退出异常列表；全池额度汇总不随筛选变化。空列表提供异常筛选专用提示，分组按钮补充可访问的选中状态。

## 升级说明

本次为管理界面补丁，无新增配置、数据结构或迁移。风控判定、冷却、调度、启停及恢复规则均保持不变；恢复仍由服务端逐条判定，凭据异常不会按风控失效恢复。

新增七项前端行为回归，覆盖状态计数、零数量入口、错误类型组合、勾选隔离、批量操作及查询刷新。全部自动化验证由 GitHub Actions 执行，发布前分支完整 CI 与发布工作流复用的完整 CI 均为门禁。

实施及失败回归记录见 [实施计划](../plan-account-abnormal-filter-20261016.md)。
