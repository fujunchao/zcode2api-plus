# v2.9.18-go

## 恢复默认阶梯冷却

- 默认按 5 / 15 / 60 分钟阶梯冷却，到期重新参与选号；连续超过三档置为失效，成功调用清零连续计数。后台自定义阶梯继续生效。
- 额外本地隔离 `ZCODE_RISK_SILENT_HOURS` 默认由 24 改为 0；历史 `last_risk_control_at` 保留用于诊断，不再默认将第一次风控延长为整号隔离一天。
- 显式设置大于零时仍启用额外隔离及恢复护栏。没有自动复活失效、停用、归档或额度耗尽账号，没有清空已有冷却记录。
- 保留请求级停止换号、重放保护和代理失败历史。

## 并发错误分类

- `3008 / 3009 / 3010` 与普通 429 分开；支持顶层和嵌套业务码。
- 同步、异步均使用独立有限退避（默认 1s/2s），不将并发限制变成整号冷却，不切换其它账号扩散重试；用尽保留原始错误码。
- 明确的其它业务码不会因模糊文案被覆盖，3009 也不再被日志硬写成 3010。

## 出站诊断与界面

- 实际发送前记录最终模型、输出上限、thinking/effort、system 分块字节数/哈希、官方固定块匹配、鉴权双头一致性及 metadata 会话关联。
- 记录账号调用前状态、阶梯连击、最近风控时间、额外本地隔离配置、模型额度及有效额度观测时间；响应沿用同一份冻结摘要。
- 分块摘要最多 16 项，未知参数只记录类别，不抄录正文、工具 schema、凭据或会话标识原文。
- `history_blocked_candidates` 明确为被历史排除的候选代理条数；保留 `history_blocked` 兼容旧解析器。
- 页面显示本地隔离和最早重新评估时间，不再把本地窗口写成“上游标记未解除”。

## 升级提示

如果部署曾显式设置 `ZCODE_RISK_SILENT_HOURS=24`，应改为 `0` 或移除覆盖，才能恢复纯阶梯。已有保护恢复形成的实际 `cooling_until` 不会被升级自动清除；请查看页面的重新评估时间并按需要人工处理。

本版本不改变模型请求内容或既有账号数据，不声称修复供应商的所有 3012 风控触发原因。

验证使用合成凭据、隔离存储和本地 HTTP 服务；分支完整 CI 与发布复用 CI 均为发布门禁。
