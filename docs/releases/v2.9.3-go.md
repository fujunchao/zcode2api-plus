# v2.9.3-go

仪表板按模型独立汇总额度，不再把 GLM-5.3 与 GLM-5.3-Flash 的余额混成一个数字。

## 功能优化

- 两个模型分别展示总额度、已用额度、剩余额度，以及对应账号数和额度项目数。
- 同一模型自动汇总多个账号、多个套餐，兼容旧额度快照和模型名称的大小写、下划线等差异。
- 无数据显示未知，已耗尽明确显示零；部分字段缺失时提示仅汇总已知值。
- 保留仪表板自动轮询和手动刷新，窄屏下模型卡片自动堆叠。
- 后台状态接口新增 `model_quotas`，既有 `quota_pool` 等字段保持兼容。

## 统计口径

- 展示非归档账号最近取得的上游额度快照；停用、冷却、失效账号仍保留账面额度，不代表当前可调度额度。
- 归档账号不计入模型总额；未取得快照的账号不虚构余额。
- 不改变模型选择、耗尽隔离、实际 Token 用量统计或上游计费规则。

## 升级

- 替换二进制或镜像并重启，刷新后台页面即可，无数据库迁移。
- 上游客户端版本保持 `3.14.4`。
- 二进制：Linux amd64/arm64、macOS amd64/arm64、Windows amd64。
- 镜像：`ghcr.io/fujunchao/zcode2api-plus:2.9.3-go` 与 `latest`。
