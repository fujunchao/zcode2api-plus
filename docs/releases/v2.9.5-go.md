# v2.9.5-go

修复手动删除代理后，没有空闲代理就错误回退直连的问题。

- 删除代理后，关联账号优先分配到剩余的启用空闲代理；没有空闲代理时，共享绑定账号数最少的代理。
- 多个账号逐个更新绑定计数、均衡分配；绑定数相同时按代理列表顺序选择，停用代理不参与补位。
- 只有完全没有启用代理时才回退直连，并同时清除旧代理 ID 和地址。
- 手动删除与批量清理复用统一选线逻辑，保留原子事务、领取风控同地址排除和账号原有状态。
- 更新删除确认框和结果提示，补充接口、存储、并发删除、事务失败回滚及前端回归测试。

不修改数据库结构或 API 字段。替换程序或镜像并重启、刷新后台页面后生效；历史上已经回退直连的账号不会自动改派，需要重新指定代理。

二进制：Linux amd64/arm64、macOS amd64/arm64、Windows amd64。
镜像：`ghcr.io/fujunchao/zcode2api-plus:2.9.5-go` 与 `latest`。
