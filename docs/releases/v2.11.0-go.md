# v2.11.0-go

## 同步 ZCode 3.16.2 客户端声明（模型请求协议未变）

本机 ZCode 客户端已由 3.15.3 升级到 **3.16.2**（官方更新日志 2026-10-19）。本版对安装包做了完整只读逆向（app.asar 27,773 个文件、CLI `zcode.cjs`、provider 配置 rev31→33），并与本机留存的 3.15.3 基线做全包差分，结论是：**模型请求主链路未变，本次只需同步伪装版本声明。**

### 逆向结论

- **模型推理请求未变**：Anthropic Messages 的端点、来源头、认证双头（`Authorization`/`x-api-key`）、归因头、`metadata.user_id`、思考参数与业务错误码（3008/3009/3010/1305 等）均与 3.15.3 一致；CLI 中 `createAnthropic`、请求 URL 拼接、`anthropic-version: 2023-06-01`、`AiSdkModelExecution` 等关键构造所在语句无变化。
- **桌面共享核心 chunk 1,065/1,074 个函数**归一化结构相同；依赖无版本变化（`ai 6.0.159`、`ai-sdk/provider-utils 4.0.27`）。
- **10 个 ZCode 账号 provider**（Zai/BigModel × individual/team/start/off-peak/highspeed）的内置 baseUrl 与模型集合逐字段未变；官方 system 提示词快照逐字节一致。
- 3.16.2 的实质变化集中在**客户端本地能力**：远程会话 Source Server、手机远控 V2（`/api/v1/remote/*`、`ws2`）、插件市场、工具搜索（默认关闭）、off-peak 执行票据、数据库迁移、托盘未读徽标、日志脱敏——均不进入网关的模型 API 链路，本版不迁移。

### 本版改动

1. **默认伪装版本 `3.15.3 → 3.16.2`**：`ZcodeClientVersion` 默认值更新；`UserAgent`、`ModelUserAgent()`、`X-ZCode-App-Version`、`app_version` 查询参数全部随常量自动派生，请求形态不变。`ZcodeClientAISDKVersion=4.0.27`、`ZcodeClientNodeMajor=24` 维持不变。
2. **防御回归**：新增 `X-ZCode-Authorization` 不透传断言。该头是 3.16.2 官方客户端新增的**可选代理路由头**，仅在服务端 `agent_configs` 下发 `proxyEndpoint.mapping` 且目标限定在 `/api/v1/ultra`、`/api/v1/ultra-zai` 时才会注入；网关继续执行"未知 `x-zcode*` 不透传"策略，不主动添加、也不会让下游伪造它。

### 兼容性与回滚

- 端点、认证、请求体、调度与数据库结构均未改，无数据迁移；
- 回滚：部署侧设 `ZCODE_CLIENT_VERSION=3.15.3` 即可让 UA/版本头/`app_version` 回到旧值（无需重编）；代码侧可 revert 本次提交；
- 观察项：上游按 `app_version` 分级下发公共配置。若 3.16.2 的验证码/领取下发语义发生变化，上线后观察 `/admin/captcha` 与领取行为，必要时用环境变量回退。

### 回归覆盖

- 版本单源：`TestDefaultClientVersionMatchesInstalledClient`、`TestClientVersionEnvironmentOverrides`、`TestNoHardcodedClientVersion`；
- 头处理：`TestClientZcodeHeadersOutcome`（含 `X-ZCode-Authorization` 不透传）；
- CI 全量：`go test ./...` + 分组重复回归 + `go test -race -count=1 ./...` + SDK/NewAPI 兼容 + Windows 代理日志 + 交叉编译 + Docker 构建。
