# v2.10.21-go

## 405 归因到线路：不再因为抽到脏线而打断整条请求

在免费代理池里，405 的常见触发源既不是账号、也不是正文，而是**出口线路**。

以 2026-10-17 的网关日志为证：

- 65 个出站端点、114 次尝试中，**21 个端点出过 405 且成功数为 0**（33 次 405，29%）；
  另外 44 条线路贡献了 65 次成功。
- 同一份内容在 **41–149 秒后换一条线路即可成功**；其中 `5cacd9de08e5` 的后续请求体
  **字节数完全相同**（460902B）。
- 30 个吃过 405 的账号里，有 5 个在别的线路上成功——账号并未被长期标记。

而旧逻辑把 405 记在**账号**上（冷却 300 s），且不把线路加入本请求的回避集合；
第二个账号再吃 405 就判「内容级」，直接返回 405 并封锁同内容 60 秒。
结果：9 次判定里 8 次是误判，96 分钟内烧掉 18 个账号、产生 79 次零出站的重放拦截。

## 行为变化

### 1. 线路级 405 画像与隔离

- 按规范化线路身份（`strictProxyIdentity`）聚合；**连续 2 次** 405 即隔离该线路，
  首档 30 分钟，再犯按 30 → 60 → 120 → 240 分钟升档。
- **一次完整成功即清零并解封**：时好时坏的线路不会被永久压死。
- 只影响新派发（选号与新绑定），**不改已有绑定、不删除任何配置**。
- 直连 / `direct_fallback` 不建档；线路配置被编辑（代次变化）后旧账作废。
- 状态存内部 meta（`line_405_state`），重启不丢，且不进入设置快照。

### 2. 选号两级候选，绝不返回「无可用账号」

`selectAccount` 先生成「不含被隔离线路」的候选；若为空则回落到全量候选并记
`line405 relax=1`。宁可继续用一条已隔离的线，也不把「线路脏」升级成「服务不可用」。

### 3. 请求级判定改按**不同且干净的线路**计数

- 判定单位从账号改为线路，阈值默认 **3** 条；命中时已脏的线路不计入。
- 理由：按账号计数会把「抽到两条脏线」误判成「内容被拒」；本次日志的 9 次判定
  里 8 次如此。
- 重放防护 TTL **保持 60 秒不变**——内容多数是好的，延长只会挡住本可成功的重试。

### 4. 首次 405 只换线、不冷却账号

- 新增 `NoteAccount405`：记录账号最近一次 405 的出口线路。
- 首次、或同一条脏线重复命中 ⇒ 只换线，不写 `cooling`、不推进阶梯，仅落错误证据
  与命中时刻。
- 同一账号**换过一条线仍然 405** ⇒ 才进入原有阶梯冷却（300/900/3600 s，超限置失效）。

### 5. 405 现在真的会「换线」

- 账号级 405 分支把当前线路加入本请求的回避集合（与 408/524 同一条出路）；
- 异步池新增 `errLine405` 承载回避线路，且**不消耗** timeout 预算。

### 6. 观测

- 隔离：`线路 X 连续 N 次 405，隔离至 …`
- 判定：`已在 N 條線路上復現、M 個帳號`
- 不冷却：`本次只换线、不冷却账号`
- `GET /admin/api/health/summary` 并列返回 `line405` 画像
  （`consecutive_405 / total_405 / ok / strikes / quarantine_until`）。

## 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `ZCODE_LINE405_MIN_STREAK` | 2 | 连续几次 405 隔离；0 = 关闭线路隔离 |
| `ZCODE_LINE405_QUARANTINE_MINUTES` | 30 | 首档隔离时长 |
| `ZCODE_LINE405_MAX_QUARANTINE_MINUTES` | 240 | 续期封顶 |
| `ZCODE_RISK_REQUEST_LEVEL_LINES` | 3 | 判请求级所需的不同干净线路数；2 = 旧行为 |
| `ZCODE_RISK_COOL_ON_FIRST` | 0 | 1 = 恢复「首次 405 即冷却」的旧行为 |

## 兼容性

- 无数据迁移；`accounts.data` 键集不变（本版未新增账号持久化字段）。
- 首次启动会新建 meta 键 `line_405_state`；回滚旧版本时它会被当作未知设置忽略，
  不影响启动。
- 异步与同步的 405 判定与处置完全一致（项目硬不变式）。

## 回归覆盖

线路画像（连续计数 / 成功清零 / 到期升档 / 成功解封 / 代次重置 / 直连忽略 / 持久化）、
两级选号（跳过隔离线 / 全隔离兜底）、`LineKey` 归并、请求级按线路计数与脏线排除、
首次 405 不冷却、同号换线后再 405 升级冷却、sync/async 同线 405 不判请求级且不登记
重放防护、非风控 405 行为不变。
