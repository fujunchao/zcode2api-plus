# v2.0.3-go

本版本合入上游核心修复，完善工具调用、思考控制和 Pi / OpenAI 客户端兼容性。

## 主要更新

- 合入上游 `7675309`：统一异步接口的账号错误分类，修复验证码并发、工具调用 ID、SOCKS5 IPv6 等问题。
- Chat Completions 与 Responses 共用工具选择及并行控制，完整保留多工具调用与结果回传。
- 支持 `none/minimal/low/medium/high` 思考档位，兼容 Pi 的 OpenAI 和 ZAI 开关式请求。
- 补齐 Responses 的项目、文本、思考摘要和工具参数流事件；修复交错工具参数与异常终止处理。
- 增加官方 OpenAI Python SDK 2.30.0、Pi 0.85.1 适配器的本地闭环回归与 CI 检查。

## 升级与兼容性

- 保留现有 Docker 非 root 用户、`/data` 和 `zcode-data` 数据卷配置。
- 不支持的工具类型、`strict:true`、`xhigh/max` 等思考档位会明确返回 HTTP 400，不再静默忽略。
- 档位预算最多占输出上限一半；需要 `high` 的完整 8192 token 预算时，将输出上限设为至少 16384。
- 开启思考但输出上限不足 2048 时明确报错；Responses 仍为无状态模式，不支持 `previous_response_id`。
- Pi 配置请使用独立提供商条目，避免把 `low/medium/high` 全映射为 `high`。

## Docker 镜像

```bash
docker pull ghcr.io/fujunchao/zcode2api-plus:2.0.3-go
```

支持 `linux/amd64` 和 `linux/arm64`，同时更新 `latest` 标签。
镜像和下方各平台二进制由此版本的 Release 工作流生成，构建期间可能尚未全部就绪。

客户端回归使用本地模拟上游；真实 Z.AI 模型的在线行为仍以实际账号环境为准。
