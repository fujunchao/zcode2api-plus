# v2.1.3-go

代理线路自动巡检（定时检测 + 自动移除 + 账号自动改派），以及直连探测不再跟随环境代理。

## 新功能

### 代理线路自动巡检

此前代理可用性检测只能手动触发（「測試直連」/「全部測試」）。本版本起，服务内置定时巡检：

- **定时检测**：默认每 30 分钟自动对所有**已启用**的代理线路执行一次可用性检测，探测目标、判据与手动检测完全一致（z.ai 两个入口 origin、生产同款 UA、三态 ok/blocked/error），无需人工触发。
- **自动移除**：每轮检测结束后，自动移除所有检测不通过的线路。
- **账号自动改派**：被移除线路上绑定的账号自动重新分配——优先绑定空閒线路（当前未绑定任何账号），无空閒线路时绑定当前绑定账号数最少的线路；多条并列时按线路表顺序，多个账号同时重绑会逐条摊开，不会挤在同一条线上；完全没有可用线路时才退回直连（同时清掉失效的出站地址）。
- **全失败保护**：若某一轮所有线路都检测失败，会先探测直连做对照——直连也不可达时判定为本机网络故障，本轮一条都不删，避免断网时清空整个线路池。
- **边界**：停用线路不探测也不移除；手工填写出站地址的账号不受影响；巡检期间被手动删除/停用的线路不会误处理。
- **日志**：每条不可用线路、每次移除、每个账号的改派/退直连逐条记录，轮末输出一行汇总（可用数、移除数、改派数、耗时），前缀 `[~] proxy-health`，便于检索排查。

环境变量：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `ZCODE_PROXY_HEALTH_ENABLED` | `true` | 自动巡检总开关 |
| `ZCODE_PROXY_HEALTH_INTERVAL` | `30` | 巡检间隔（分钟，最小 1） |

> **行为变化提醒**：自动巡检默认开启，失效线路会被**自动删除**。如果希望线路只由人工管理，请设置 `ZCODE_PROXY_HEALTH_ENABLED=false`。

## 修复

- **直连探测不再跟随环境代理**：此前「測試直連」在设置了 `HTTP_PROXY`/`HTTPS_PROXY` 的环境里实际测的是环境代理的出口，与网关真实出站（裸 Transport，绝不走环境代理）语义不一致。现在直连探测显式禁用环境代理，测到的就是真实的直连出口。

## 升级

```bash
docker compose pull && docker compose up -d
```

如需调整巡检行为，在 `.env` 或 compose 环境中设置上表两个变量即可。
