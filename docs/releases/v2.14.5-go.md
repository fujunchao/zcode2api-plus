# v2.14.5-go

提前登记 ZCode 4.0.0 客户端身份对应的 system 文案档案，为把默认伪装版本切到 4.0.0 做准备；默认请求形态不变。

## 背景

本机 ZCode 4.0.0（4.0.0.10870 / build `3bc8a247`）与 3.19.1 完整快照全量差分后确认：默认桌面条件的三块 system
（35 / 1,233 / 4,564 B）、Desktop Context 1,100 B、来源头、SDK 版本（anthropic 3.0.81 / openai 3.0.65 /
provider-utils 4.0.27 与 4.0.39）、签名模块与随包模型目录均逐字节/逐项相同。4.0.0 的实质增量在客户端侧
OpenAI Responses 无状态加密推理回放，不影响网关的 Anthropic 主链。

## 变更

- `ZcodeSystemProfileForExact` 增加 `4.0.0 → 3191` 精确映射；相邻未核验版本（4.0 / 4.0.1 / 4.0.0.1）仍回落
  legacy 并告警，不做前缀匹配。
- 新增回归：4.0.0 与 3.19.1 的三块 system、缓存布局与桌面上下文逐字节一致；档案隔离与回落语义不变。
- 注释与文档记录 4.0.0 复核结论，明确**不复制**一份正文相同的 4000 JSON。

默认 `ZCODE_CLIENT_VERSION` 仍为 `3.19.1`；本次不改变接口、配置项、数据结构与默认请求形态。

## 升级与回退

镜像：`ghcr.io/fujunchao/zcode2api-plus:2.14.5-go`，同时更新 `latest`。
二进制：Linux amd64/arm64、macOS amd64/arm64、Windows amd64。

本次没有数据库迁移。回退使用 `2.14.4-go` 镜像；只想回退版本声明仍用 `ZCODE_CLIENT_VERSION`（3191 档案保留）。

复核与探针记录见 [implementation-zcode-4.0.0-profile-20261123.md](../implementation-zcode-4.0.0-profile-20261123.md)。
