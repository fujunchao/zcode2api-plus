# v2.9.7-go

新增计费端点不可达和领取可疑请求的故障代理淘汰，覆盖新老账号。

- 通过命名代理查询余额、预览领取资格或领取套餐时，遇到连接/DNS/TLS/CONNECT/SOCKS 失败、超时、成功响应中断或 HTTP 407，删除失败请求使用的原代理。
- 领取接口明确返回 `3012`、`unusual activity`、`suspicious request` 或中文可疑请求时，同样淘汰代理；不再要求账号是新号、无额度或没有历史使用记录。
- 删除及所有关联账号改派共用原子事务。继续按“空闲优先，否则绑定最少”分配，排除原 URL，停用代理不参与，无替代线路时清除旧绑定并回退直连。
- 领取遇到故障后停止在原线路继续领取，不循环换代理重试；已成功领取的记录和账号原有状态保留，批量后续账号读取改派后的最新绑定。
- 改派或换令牌后不复用旧身份的额度缓存/在途结果，迟到失败也不能误删新的代理。
- 普通鉴权、限流、上游服务错误、验证码失败、已领取、名额耗尽、无可领套餐、响应格式异常及取消，不单凭这些信号删除代理。
- 老账号单纯空额度仍不删除代理；v2.9.6 的新号双次空额度检测保持不变。两种故障规则独立生效。
- 非法的已配置代理不再静默回退直连；直连、手工地址和绕过账号线路的注入客户端不会误删代理池里的命名线路。
- 后台手动、自动/定时领取、资格预览、额度监控和 CLI 对应入口共用处理；补充隔离 HTTP/SQLite 回归，并在 CI 重复验证 20 次。

不修改数据库结构。更新程序或镜像并重启服务后生效；不扫描、追溯删除历史代理，只在相应请求出现已确认故障时执行。

二进制：Linux amd64/arm64、macOS amd64/arm64、Windows amd64。
镜像：`ghcr.io/fujunchao/zcode2api-plus:2.9.7-go` 与 `latest`。
