# v2.10.20-go

## 单号钉住：把流量临时固定在一个账号上

真机复验时最麻烦的一步是「让请求一定打到这个号」——此前只能把其余 60 个账号逐个停用。
本版加一个**钉住**动作：钉住期间，全部模型请求在资格闸门之后优先选中被钉的账号。

**账号池每一行右侧新增钉住按钮**：

- 未钉住：`Pin` 图标，点击即钉 30 分钟，toast 提示。
- 钉住在本行：按钮变为 `PinOff`，再点解除；账号名旁显示 `釘住 · 剩 N 分` 徽标。
- 钉在别的行：点其他行即改钉到该行（全局单值）。

**行为约定**：

- 只影响选号，不改账号状态：被钉的号若在冷却/停用/线路不可用，或本请求已试过它，
  选号**静默回落**正常轮询，请求不会失败；回落原因每次钉住只记一条日志（避免刷屏）。
- **不推进轮转游标**：解除钉住后，正常轮询的顺序与钉之前一致。
- **进程内 + TTL**：不落库、不进 `accounts.data`，重启即清；默认 30 分钟，API 允许 5–1440 分钟。
- 归档账号拒绝钉住（归档即停止调用，钉它只会让请求全部回落）。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/admin/api/accounts/{account_id}/pin` | body `{"minutes":30}` 可省略；越界返回 400 |
| `GET` | `/admin/api/pin` | `{"pinned":{id,name,until}}`，无则 `{"pinned":null}` |
| `DELETE` | `/admin/api/pin` | 解除（幂等） |

`GET /admin/api/accounts` 顶层新增 `pinned` 字段（同结构），账号行据此显示徽标——
沿用现有 5 秒轮询，不为钉住单独加查询。

## 兼容性

- 无数据迁移；`accounts.data` 键集不变。
- 前端改动仅限账号池页（按钮 + 徽标），`frontend/dist` 已随本版重建。
- 钉住是**进程内**状态：多副本部署时只对处理该请求的实例生效；单容器部署无差别。

## 回归覆盖

钉住压过额度排序、钉住号冷却时回落正常选号、TTL 到期自动失效且不推进轮转游标、
归档账号拒绝钉住、解除幂等、API 回路（POST→列表→GET→DELETE）×2 与越界时长 400。

所有自动化验证由 GitHub Actions 执行，分支 CI 与发布工作流复用的完整 CI 均为门禁。
