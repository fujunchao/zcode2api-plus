## ZCode 3.15.1 兼容修补

- 默认客户端标识由 3.14.5 同步为 3.15.1。模型与非模型请求仍共用版本来源，保持原有的两种 User-Agent 形态。
- 保留 provider-utils 4.0.27、现有 Node 兼容声明和固定提示词；不照搬桌面 Gen UI 上下文，不将版本同步描述为供应商 405 风控修复。
- 同步维护环境样例与版本回归；显式设置的 `ZCODE_CLIENT_VERSION`、`UPSTREAM_USER_AGENT` 仍优先，不会被升级自动改写。

## 账号上下文隔离

以下请求头绑定特定账号、订阅或高速卡，目前不属于网关支持的普通推理契约：

- `X-Highspeed-Card-ID`
- `X-Bigmodel-Authorization`
- `Bigmodel-Target-Type`
- `Bigmodel-Organization`
- `Bigmodel-Project`

三个同步推理接口及 `/async/v1/messages` 遇到任一上述头时，在选号/验证码/建票/出站之前返回 **HTTP 400**，错误类型为 `unsupported_account_context`。大小写、空值和多值均受约束；错误只报告头名，不回显令牌、卡 ID 或组织/项目值。

这是显式拒绝，不会把高速卡请求悄悄转成普通计费请求。上游请求构造层另有防线，这类客户端错误不标记池中账号失效。网关鉴权仍优先执行。

不带这些头的正常请求保持兼容：trace/session/query、Anthropic beta 和合法自定义头继续按原有规则处理，换号/同号重试及异步归因语义不变。

## 升级提示

- 普通客户端若被中间代理额外附加上述账号绑定头，需移除这些非必要头；真正需要订阅高速卡的调用应使用支持该权益的客户端。本版本没有开放 HighSpeed、团队双凭据或卡回退功能。
- 替换二进制/镜像并重启即可，无数据库迁移，不清空额度、冷却、静默记录，不自动恢复失效账号。
- 若部署固定了旧客户端标识或非模型 User-Agent，请自行核对覆盖值；升级只更新默认值。
- 保持 v2.9.19-go 的默认 24 小时本地风控静默、现有重试预算和账号保护策略。
- 第二批 SSE 多行/用量及 API Key 兑换业务错误归因修复不在本版本范围内。

## 验证与发布门禁

回归通过真实 HTTP 入口和本地模拟上游覆盖：三种同步协议、JWT/API Key、JSON/SSE、五类头的大小写/空值/多值、空账号池、鉴权优先、合法请求重试、异步建票前拒绝以及配置进程启动时的环境覆盖。

测试仅使用合成凭据和隔离目录，不读取运行数据。分支完整 CI 和 release.yml 复用的完整 CI 均是发布前置门禁；不在开发机运行自动化测试。
